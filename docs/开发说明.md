# 开发与源码运行

普通使用者下载 Releases 中的 Windows 免安装包即可，不需要本页步骤。

核心脚本 excel_unmerge_fill.py 使用 Python 标准库，excel_unmerge_gui.py 是 Tk 桌面界面。最低 Python 版本为 3.8，打包环境使用 Python 3.12。源码界面需要 Tcl/Tk；Windows 发布程序已打包运行环境。

源码运行：
- python excel_unmerge_gui.py
- python excel_unmerge_fill.py "原始数据.xlsx"
- python excel_unmerge_fill.py "原始数据.xlsx" --all-merges
- python excel_unmerge_fill.py "原始数据.xlsx" --sheet "明细"

测试：
- python -m pip install openpyxl==3.1.5
- python -m unittest discover -s tests -v
- python excel_unmerge_gui.py --self-test
- python excel_unmerge_gui.py --self-test --self-test-log "self-test.log"

测试工作簿由代码合成。不要提交业务文件。openpyxl 只作为测试依赖，不是运行程序的依赖。

Windows 打包：
- python -m pip install pyinstaller==6.22.3
- python -m PyInstaller --noconfirm --clean --onefile --windowed --name ExcelTools excel_unmerge_gui.py

GitHub Actions 在 main 的 push、PR 和手动触发时执行 Windows 测试和构建，失败时收集打包自检诊断日志。将 dist/ExcelTools.exe 与 packaging/使用说明.txt 打包。确认测试及打包后自检成功，并获得发布授权，再将同一产物上传为 Release 的 ExcelTools-Windows-x64.zip。固定下载入口为 releases/latest/download/ExcelTools-Windows-x64.zip。

v1.1 的合同、任务状态及实际验收记录见 [版本目录](releases/v1.1/progress_v1.1.md)。本地候选包使用 `dist/ExcelTools-v1.1-Windows-x64.zip`；文件存在及具体哈希以本轮验收记录为准。

打包自检在独立中文目录、不同工作目录、清理过的 Python/Tcl 环境下运行；Windows runner 仍有系统预装组件，这项验证不等同于在所有用户电脑上完成验收。
