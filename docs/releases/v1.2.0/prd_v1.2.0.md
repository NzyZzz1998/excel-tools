# 数据型合表与拆表

## 执行基线与选择

事实源：已发布 v1.1.1，起点 main/b48e97dd77bcd32c1508eab076a924568a6d54bf；现有拆分填充可处理 104MB 月表。历史性能只适用于原功能，不能作为新工具成绩。上游调研参考 Excel Branch Merger（合表与来源追溯）、qsv（按行/列拆分）；仅借鉴思路，无复制其实现或引入其运行时。

候选最小方案仅做固定行数拆表，不能解决多日数据汇总；推荐两项数据工具，复用本地免安装入口；扩展方案包含对账、清洗、报表模板，需要额外业务合同，本轮延后。用户于本轮明确选择“以数据为主：保留值、编号和日期，输出整洁的新表”，本合同据此落地并在界面常驻说明。编号、日期和零值语义是必保合同，图片、宏、图表、公式及全样式复制不属于这两项新工具。原拆分填充的保真合同不变。

## 范围与合同

| ID | 行为 | 实际验收出口 |
|---|---|---|
| T-01 | 用户逐个添加文件，显式选择工作表及表头行。选择范围内隐藏工作表可处理，不暗中遍历全部表。预览读取真实表头；明确它不完成全表校验。 | 文件、工作表、表头和结果目录可见；配置变更使预览失效。 |
| T-02 | 合表以首个输入列序为准，trim 后表头非空、唯一且列集合相同；可按列名重排，缺/多列拒绝。重复相同输入拒绝。 | 不吞列、不合并重名字段；非空数据行按输入与源行顺序恰好一次。 |
| T-03 | 拆表每次一个工作表，按固定数据行数（默认100000，不含表头）或某列不同值分组。每份重复表头；超Excel每表1048576行时分卷。 | 边界N±1和Excel行上限可测，无漏行/重复；空表有明确0行结果。 |
| T-04 | 值、文本编号、布尔、错误值和数字格式保留；日期保留原序列及日期系统。混1900/1904输入拒绝。公式一律拒绝，提示在副本粘贴为值；选中表头及数据范围的合并拒绝，提示先拆分填充。 | XML与独立读回核验类型/值/格式；后期发现异常也不发布半套结果。 |
| T-05 | 可附加来源文件完整路径、工作表、原行号，原列同名时新增来源名顺延。分组区分空值、空文本、数字、文本、布尔、日期序列；同数值不因无关格式不同而拆组。 | 本地manifest记录输入身份、分组语义、输出分卷及行数，保留可追溯性。 |
| T-06 | 输入只读，全部文件和manifest写入独有临时任务目录；整批完成后排他创建结果父目录并一次重命名发布“结果”子目录。失败/取消清理本次暂存，不改源和既有结果。 | 无正式半套文件；同名/并发结果不覆盖；清理失败明确提示残片及原错误。 |
| T-07 | 逐行XML读取；共享字符串与分组明细使用磁盘SQLite，有界缓存；不全表list，不为每个组常驻writer。单次最多1000个输出文件，超限明确要求减少分组或加大分片。 | 大文件、共享字符串压力和高基数分组分别检查；真实阶段/已处理行与耗时，不虚构百分比或剩余时间。 |
| T-08 | 新工具后台线程仅传普通数据/队列/Event；运行时禁改配置与重复提交，关闭请求取消并保留窗口等清理结束。原页与新工具不能同时启动任务。 | 取消、失败、关闭、线程启动失败、再次运行和主窗口回收有真实Tk检查。 |

100000行默认与1000文件上限是本轮可逆工程决策，用于可用性和防止意外海量文件，并非用户给定规模/SLA。分组输出采用序号＋安全截断标签命名，完整组值在本地manifest；不会将真实业务值提交到仓库。

## 用户流程、状态与出口

主窗口“合表与拆表”→添加文件→选择表与表头行→添加源列表→选模式/输出目录→检查表头→查看字段与兼容结果→开始→后台读取/分组/写入/发布→显示结果目录、文件数、数据行数与manifest。错误定位源文件/表/单元格，修改后重新检查/重跑；不支持中途恢复或跨重启任务恢复。

状态为 idle → inspecting/previewing/running → succeeded/failed/cancelled。未选择/检查失败不启动；每次执行重新检查输入元信息及表头，在处理后核对size/mtime_ns。输入在运行期间不应外部编辑；元信息不是密码学快照或操作系统独占锁。

| 命令 | 是否后台执行 | 当前值/已保存值 | 可见反馈 | 退出与失败 |
|---|---|---|---|---|
| 添加/移除/改选项 | 文件列表读取按需后台 | 当前配置保留，旧检查失效 | 实际源列表与字段 | 对话框取消保留原选择 |
| 检查表头 | 是 | 不生成结果文件 | 真表头、日期系统、匹配错误 | 失败留窗口与输入供修正 |
| 开始/无变化再次开始 | 是；运行中重复点击无效 | 快照本次配置；结果永不覆盖 | 阶段、行数、计时与最终目录 | 任意错误无正式新结果 |
| 取消 | 发Event，不保存部分结果 | 当前输入保留 | 请求取消→完成清理 | 不提供断点继续 |
| 关闭 | 空闲直接关；运行时发取消 | 当前配置仅在窗口内 | 等清理后再次关闭 | 主窗口也不能绕过取消 |
| 重置 | 本轮无独立按钮 | 移除源列表重新选 | 预览失效 | 重启恢复默认配置 |
| 打开结果目录 | 仅系统本地打开 | 不修改结果 | 文件管理器或路径错误提示 | 可复制完整路径 |

## 工程与影响

新 `excel_table_io.py` 定义 Cell、TableReader、XlsxWriter、TableCancelled；新 `excel_table_tools.py` 定义 TableSource、TaskResult、inspect_workbook/preview_sources/run_tables；新 `excel_table_gui.py` 原生Toplevel，复用同一Tk解释器，根入口修改 `excel_unmerge_gui.py`。旧 `excel_unmerge_fill.py` 不改。运行时仍stdlib，SQLite为任务级临时缓存，不是业务数据库，无迁移、网络、账户或云服务。磁盘需容纳未压缩XML、SQLite和最终结果；原目录只读、输出目录须可写。

数据输入为所选xlsx/xlsm，输出为新xlsx，表头之前行不输出；全空/仅格式行跳过，0、False、空格和显式空文本不会转数值或公式。输入dim不作为行数事实。输出样式只保留数字格式，不保留批注、超链接、图片、宏、合并、行列尺寸等。源工作簿保真操作继续使用原工具。

日志记录任务级路径、计数、阶段与错误；实际业务内容只留本地源/结果与忽略的验收目录。新增测试文件、便携自检、打包说明、README/使用说明同步受影响。回退是关闭新工具使用已发布v1.1.1，无自动升级和配置迁移。

| 原型交付门禁 | 本轮要求 |
|---|---|
| 交付文件 | `excel_table_gui.py`＋已核对 `excel_unmerge_gui.py` 原生Tk即增量可运行表达物；本轮不以低保真线框替代，按继续实施授权迭代。 |
| 状态与出口 | 真窗口验证空、加载、禁用、正常、错、取消、关闭、结果打开；结果写入仅引擎真实成功后成立。 |
| 模拟边界 | 合成输入驱动真实Tk和引擎；文件选择可受控替代；Agent操作不证明真实用户采用。 |
| 浏览器验证 | 原生桌面不适用浏览器，等价验证默认/最小窗口、控件边界、回调错误与独立EXE。 |
| 结论回写 | progress与acceptance回写实测，不提前称原型/候选通过；既有拆分填充状态与停止恢复不得退化。 |

## 验收与承接

采用L0审查＋L1独立反例＋L2自动测试、原生GUI、真实数据和便携包。独立openpyxl只作为输出oracle；重点核对类型、表头重排、无遗漏、容量、异常原子性、取消和资源占用。输入实际大表无需重做旧拆分填充性能测试，但新工具须给独立测量，不沿用旧成绩。Windows Excel读回视本机能力取证，缺失明确记录。
