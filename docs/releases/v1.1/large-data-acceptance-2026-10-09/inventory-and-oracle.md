## 输出校验方式

[validate_large.py](validate_large.py) 不导入处理引擎，不调用引擎生成期望。它读取源合并范围，逐行保留必要锚点，以源锚点的 payload、类型与样式独立推导预期目标格，然后与输出每一格比较。它支持多工作表、任意合并数量和默认/全部拆分两种规则。

内存只保留当前源行、当前输出行、合并索引和锚点，以及工作表行外设置；不建立百万单元格字典，不使用 minidom。验证涵盖所有原格/新格的内容和类型、样式索引与未变 styles 部件、行属性/顺序、保留合并、声明范围、非目标工作表结构，以及全部非目标 ZIP 部件逐字节哈希。源/输出在验证前后再核对 SHA256。原来没有 dimension 时，不要求输出新建 dimension。

命令形式：

```text
python validate_large.py SOURCE.xlsx OUTPUT.xlsx --report RESULT.json
python validate_large.py SOURCE.xlsx OUTPUT.xlsx --all-merges --report RESULT.json
```

可用性检查已完成：10 个合成场景通过，包括正确的两种规则、无 dimension 输入，以及刻意破坏值、类型、目标样式、缺格、dimension、未改部件和合并内隐藏独立内容的拒绝检测，见 [validator-smoke.json](validator-smoke.json)。另外，已对原先独立验收通过的 Top50 默认/全部输出各进行一次全量核对，均通过；该结果用于检验 oracle 与既有业务规则兼容，不代表本次 19 万行输出已验证。
