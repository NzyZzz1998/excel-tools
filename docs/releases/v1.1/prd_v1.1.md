## 用户流程与状态

选择文件后“开始处理”新建一次任务，清空旧日志，固定本轮拆分选项。每个文件状态为待处理→处理中→成功/无需处理/失败。任务暂停时剩余项仍是待处理；成功文件是否有输出由结果区明确区分。

| 命令 | 输入及结果 | 反馈与出口 |
|---|---|---|
| 开始处理 | 使用当前选择和选项创建新任务；运行中拒绝重入。 | 禁用文件/选项修改，逐文件显示名称及已完成数；正常结束后显示总结果。 |
| 仅重试失败项 | 仅选择最新状态为失败的文件；沿用该任务的选项快照。 | 追加本轮日志，保留以前成功项、待处理项和输出目录；失败仍可再次重试。 |
| 停止后续处理 | 设置停止请求；不打断当前文件转换或保存。 | 显示“当前文件完成后停止”；剩余项不计完成。重复请求幂等。 |
| 继续处理 | 只处理此前未开始的文件，沿用该任务选项。 | 追加日志，不重跑成功或失败项；既有失败仍可单独重试。 |
| 关闭 | 空闲可关闭；运行中先请求安全停止。 | 当前文件结束后保留结果窗口，用户再次关闭。不会直接终止写入线程。 |
| 选择新文件 | 空闲时改变待开始的文件选择，不启动处理。 | 新任务开始前仍可看旧结果；开始新任务后重置恢复状态。 |
| 无需处理 | 没有符合条件的合并区域。 | 完成计数增加，单独显示“无需处理”，不生成冗余文件。 |

权限沿用本机文件读写权限；输出独占创建并加后缀，原文件不写入。运行异常只影响当前文件，其余文件继续或按停止请求暂停。任务和选项快照只保存在内存，重启后不恢复。外部修改源文件后重试会读取其最新磁盘内容。

## 工程与表达物

- 引擎：`excel_unmerge_fill.py`；接口仍返回 `(output, stats)`，不新增运行时依赖。
- GUI：`excel_unmerge_gui.py`；线程只读参数副本、只发队列事件；主线程操作 Tk。
- 批处理：兼容原三参数调用，新增可选停止事件；`started`、`result`、`done` 明确区分。
- 存储：同目录新增输出；无配置迁移、数据库、服务端或权限模型变更。
- 诊断：`--self-test-log PATH` 记录打包自检结果/异常，窗口化环境仍可定位；不用业务数据作日志。
- UI 沿用现有 Tk 布局，增加重试/继续/停止动作；本项目是原生桌面增量，使用实际 Tk 窗口作为可运行表达物，浏览器 HTML 不是本产品运行面。用户已要求直接实施，不额外设置原型审批。

| 原型交付门禁 | 本轮要求 |

| 状态与出口 | 覆盖空、运行、失败、停止请求、已停止、恢复、完成及关闭；控制可用状态由任务状态决定。 |

## 验证与风险

采用 L0 代码审查 + L2 合成数据上的实际执行；每条 F-ID 对应原/结果状态或自动断言。新增 serializer、DOM 重排和任务恢复是主要回归面；出错先回退受影响模块，不能以忽略异常换取“成功”。

全套现有测试与新增回归、两种窗口尺寸、写包故障注入、本地同源 EXE 自检是本轮开发完成证据。Windows 10/干净机、Excel/WPS 真实客户端、正式 Release 仍沿用待验证边界，不阻止本地实现，但不能声称全部正式使用环境验收通过。

## 2026-10-09 · 业务验收补充契约

用户提供 `testfile/期间缺货Top20` 下 5 个工作簿用于实际验收，授权在隔离副本上核对两种拆分规则。F-01 补充：已处理且原有 `dimension` 的工作表，输出范围须覆盖全部实体单元格及保留合并，不能只覆盖新填充区域；保留已有更大范围。无匹配的表仍按原合同不改动。使用非业务合成用例、独立 XML 核对、默认流式读取与本机 Excel 读取补证；不修改原文件、不把源导出报表的业务汇总口径改成重新计算。

## 2026-10-09 · 深验与发布补充契约

F-01：复制文本应保留源、目标不同的继承 `xml:space` 语义；已被地址解析器接受的小写／绝对地址必须一致参与填充、公式和元数据保护，重复等价地址拒绝无输出。结果名称被目录占用时沿用自动加序号合同，真实权限失败仍报错。

F-03：按同一日明细的 1/7/31 倍模拟负载，对比 v1.0.0 和当前引擎的耗时、峰值工作集／专用内存，并独立核对结果与源文件哈希。不把重复表头、汇总的负载模拟当作真实月度业务验收，不新增未知业务 SLA。保留完整 DOM 的资源边界，流式引擎与任意大数据容量承诺不进入本次修复。

F-07：重建候选后补齐同源构建、实际 EXE 业务结果、真实 Excel 内容对照；发布附件必须与该候选哈希一致，重新下载核对版本及隔离自检。历史证据仅在代码或输出等价且适用范围清晰时继承。

用户后续纠正：日明细已有约 5 万行。原 F-03 的 Top50 报表 ×31 样本仅是小报表压力数据，不能作为真实明细／月报的验收出口；发布暂缓，需先定位真实明细文件并重设代表性负载，禁止把 1.25 万行称为该用户月度规模。
