# v1.1 开发计划

来源：[PRD](prd_v1.1.md)；上游：[REV-20261008-01](../../reviews/2026-10-08-review.md)。目标版本 v1.1，授权为本地实现、测试、打包，不含远端发布。

后续 Git 同步已于 2026-10-09 获得用户明确授权，仅提交并推送当前 `origin/main`；tag、Release 及包上传保持未执行，范围见 [progress](progress_v1.1.md)。

| 任务 | 合同 | 文件 / 工作 | 验证及完成条件 |
|---|---|---|---|
| T-01 | F-01/F-02 | 引擎序列化保真、元数据锚点明确拒绝；新增引擎回归。 | 特殊字符/前缀/CDATA 解析语义一致；vm/cm 拒绝无输出；既有类型与公式行为保持。 |
| T-02 | F-03 | 稀疏冲突检查、批量整理行/单元格顺序。 | 基准结果正确、耗时改善且无非目标修改；原有隐藏内容拒绝通过。 |
| T-03 | F-04/F-05/F-06 | GUI 错误解释、开始事件、状态记录、重试/继续、文件边界停止。 | 真实窗口混合结果、停止与恢复、选项快照、关闭与防重入测试；成功项不重复输出。 |
| T-04 | F-07 | 版本与文档、自检日志、PR 检查/失败日志、本地便携包。 | 程序与说明显示 v1.1；测试通过，同源构建、自检通过，记录 SHA 与依赖版本。 |

实施顺序：T-01/T-02 同一引擎负责人；T-03 独立 GUI 负责人并行；主代理维护合同与用户文档。集成后独立审查/测试，再执行 T-04 的打包。不得在源码仍变化时把包标为最终候选。

风险/回退：serializer 回归影响整表，任何非目标语义变化必须修复后再验证；DOM 顺序或 sibling 链错误时回退该重排实现；批次状态误判时禁用恢复动作并修复，禁止自动重跑全任务。没有数据迁移，旧版本程序可继续使用，但已知保真缺陷不能被回退描述掩盖。

开放问题：版本冲突已由用户确认 v1.1；其余本轮范围无阻塞。正式环境人工验证另列清单。过程记 [dev log](dev_log_v1.1.md)，任务状态记 [progress](progress_v1.1.md)；不扩展至 PRD 延后项。
