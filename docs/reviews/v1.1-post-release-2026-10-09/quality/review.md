## 已确认项

### P3：写入错误叠加结果被占用时，清理异常覆盖原始原因，并留下最终命名的半成品

位置：`excel_unmerge_fill.py:651`（直接独占创建最终路径）；`excel_unmerge_fill.py:675–677`（异常处理中直接 unlink，再抛出）。

触发：本次输出写到第二个 ZIP 成员时出现磁盘写入错误，同时另一个读者已打开这个正在写入的最终 `.xlsx`，允许读写但不允许删除。合成复现采用真实 Win32 只读文件句柄阻止删除，注入 `OSError(ENOSPC)` 模拟写盘失败；这不是常态路径，不能写成普通处理必然留下半成品。

实测：向调用方传播的是 `PermissionError` / WinError 32，原始 ENOSPC 仅留在异常 context；新 `_2.xlsx` 残留 376 字节、只有一个 ZIP 成员，不是有效工作簿。源文件与预先存在的结果 SHA 都不变。读句柄在探针结束时关闭，未触碰任何用户程序。[复现脚本](synthetic_probes.py)、[原始结果](synthetic-probe-results.json)。

最小方向：与主审强制终止场景一起设计同目录临时结果、完整关闭验证后再发布到最终名称，并保持独占防覆盖；清理失败至少保留原始写入异常，同时明确提示残片路径。补一条真实文件占用的故障测试。现有 `tests/test_engine_regressions.py:330` 只注入普通写入异常，未覆盖 unlink 本身失败；`tests/test_streaming_engine.py:117` 覆盖临时写入失败和关闭，不等价于此场景。

与合同的关系：PRD `:91` 要求失败清理本次半成品，F-04 `:25` 要求原因和技术详情。一般异常已有断言支撑；上述外部锁条件下无法满足绝对清理，且原始写入原因未直接呈现。外部强制终止属于主审另外记录的证据，不由本探针重复声称。

## 已证伪／不足以报缺陷的候选

- **继承行／列样式造成日期变数字**：合成源单元格没有显式 `s`，只设置行或列日期样式。本机 Excel 16.0 / build 17932 实际把源锚点也读取为 General；输出没有从一个日期显示变为数字，候选未获支持。未列为缺陷。使用独立隐藏 Excel 实例、只读打开、未保存，退出后延时确认 PID 已消失。[原始观察](inherited-styles-probe.json)、[退出确认](style-probe-delayed-exit-check.json)、[生成器](prepare_style_fixtures.py)、[只读 Excel 探针](probe_inherited_styles.ps1)。
- **格式化 XML 导致流式路径明显退化**：RowSpoolBuilder 确实保留并合并行间空白为一个文本节点。8k／16k／32k 行紧凑 XML 分别约 0.127／0.249／0.510 秒；带 8 空格缩进的版本约 0.142／0.286／0.611 秒，最后保留 288,009 个行间空白字符。此小样本未显示可确认的失控增长，不据此推断大文件故障或提出紧急优化；这是 parser 阶段探针，不是完整应用基准。[结果](synthetic-probe-results.json)。
