v1.1 Windows 免安装版，解压后双击 **ExcelTools.exe**，无需安装 Python、Excel 或运行库。

- 修复处理合并区域时，同表其他文本回车及提示换行、制表符被改变的问题。
- 修复源表范围声明不准确时，处理结果未覆盖全部已有数据、导致流式读取遗漏的问题。
- 改善大工作表和宽合并区域的处理效率。
- 新增“仅重试失败项”，保留已经成功的结果。
- 新增文件完成后安全停止和继续剩余文件，显示当前文件进度。
- 常见失败提供中文恢复指引，保留技术详情。
- 对单元格内图片等含未支持元数据的合并格明确拒绝，避免填充成错误值。

继续支持 .xlsx / .xlsm、默认保留横向表头、原文件保留及同目录另存。工作表选择仍通过源码命令行的 `--sheet` 使用；桌面版默认处理全部工作表。

下载下方 **ExcelTools-Windows-x64.zip**，解压后使用。GitHub 自动附带的 Source code 是供开发者维护的源码。

适用 Windows 10 / 11，64 位。数据在本机处理，不上传网络。

发布前应核对本版本的测试、打包自检及候选哈希记录；本地验证见 `docs/releases/v1.1/verification_v1.1.md`。真实业务文件和 Excel/WPS 客户端兼容性仍需按实际场景核对。
