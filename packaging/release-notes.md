v1.1.1 Windows 免安装版。

- 显示当前文件的处理阶段、已用时和可用的行数进度，长任务更容易判断当前状态。
- 结果完整保存后才使用正式文件名，避免强制退出留下看似完成的工作簿；保存与清理同时失败时保留原始错误及残片位置。
- 明确“待开始选择”和“上次任务”，重试/继续时显示实际处理对象，保留成功文件和首次处理规则。

下载并完整解压 **ExcelTools-Windows-x64.zip**，运行 **ExcelTools.exe**，确认标题为 **v1.1.1**。无需安装 Python 或 Excel。升级时使用新目录，旧快捷方式不会自动更新。

支持 .xlsx / .xlsm，默认保留横向表头，结果同目录另存，原文件及既有结果不覆盖。数据只在本机处理，程序不执行宏。

大文件需要系统临时目录和结果目录的可用空间；文件进度条按完成文件数计数，停止仍等待当前文件安全结束。强制结束可能留下 .part 临时文件，它不是有效交付结果。

本版属于体验与可靠性修补，没有承诺速度提升。具体候选身份、验收和限制见仓库 v1.1.1 版本目录；更大或不同结构的工作簿、WPS和干净Windows环境仍需对应验证。

没有数据迁移。回退可使用 [v1.1 历史包](https://github.com/NzyZzz1998/excel-tools/releases/tag/v1.1) 重新处理保留的原工作簿。
