Windows 免安装版，解压后双击 **ExcelTools.exe**，无需安装 Python、Excel 或运行库。

- 支持 .xlsx / .xlsm 批量拆分合并行，原值填充到每一行。
- 默认保留横向表头，可选择拆开全部合并单元格。
- 显示按文件的处理进度，区分已保存、无需处理和失败。
- 处理完成后可以直接打开结果目录，原文件始终保留。
- 改善 Windows 高 DPI 显示，完整运行环境打包在程序中。

下载下方 **ExcelTools-Windows-x64.zip**，解压后使用。GitHub 自动附带的 Source code 是供开发者维护的源码。

适用 Windows 10 / 11，64 位。数据在本机处理，不上传网络。

发布前执行合成文件测试及打包后的窗口、结果展示和 Excel 处理自检；已在 Windows 构建环境验证，不代表已核对所有业务文件。
