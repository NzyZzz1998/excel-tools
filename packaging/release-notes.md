v1.1 Windows 免安装版。下载 **ExcelTools-Windows-x64.zip**，完整解压后双击 **ExcelTools.exe**，无需安装 Python、Excel 或额外运行库。

- 大工作表改为逐行处理并使用临时文件，降低整表载入引起的内存压力。本机约19.1万行、14列日明细实测约1分钟、峰值内存约75MB，输出完整核对通过；该数字不是所有月报的速度或容量保证。
- 修复文本回车、提示中的换行／制表符、继承的首尾空格规则被改变的问题。
- 修复特殊单元格地址漏填／重复格，以及源表范围声明不准确导致读取遗漏的问题。
- 新增仅重试失败项、安全停止后续文件及继续剩余文件，显示当前处理文件。
- 常见失败提供中文恢复指引；线程创建时内存不足也能恢复操作。
- 输出重名自动加序号；不支持的合并富值、公式、隐藏独立内容及参与拆分的重叠合并明确拒绝。

支持 .xlsx / .xlsm，默认保留横向表头，原文件保留，结果同目录另存。数据只在本机处理，程序不执行宏。

升级时先关闭旧版，将新版解压到新目录，运行其中的程序并确认标题为 **v1.1**。旧快捷方式可能仍指向 v1.0.0；GitHub 自动附带的 Source code 供开发者维护使用。

大表需要系统临时目录的额外磁盘空间。停止操作会等待当前文件结束。约100MB真实月报、WPS及干净Windows环境尚未完成实测；本机Windows11和Excel的结果不代表所有环境。

没有数据迁移。如需回退，可下载 [v1.0.0 历史包](https://github.com/NzyZzz1998/excel-tools/releases/tag/v1.0.0)，使用保留的原工作簿重新处理；旧版仍有已知保真和大文件性能问题。
