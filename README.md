# Excel 数据处理工具

面向 Windows 的免安装桌面工具：把 Excel 合并行拆开，将原值填充到每一行。

**[下载 Windows 免安装版](https://github.com/NzyZzz1998/excel-tools/releases/latest/download/ExcelTools-Windows-x64.zip)** · [版本说明](https://github.com/NzyZzz1998/excel-tools/releases/latest)

## 直接使用

1. 下载并解压 ExcelTools-Windows-x64.zip。
2. 双击 **ExcelTools.exe**。
3. 选择一个或多个 Excel 文件，点击“开始处理”。
4. 查看处理结果，点击“打开结果目录”找到新文件。

无需安装 Python、Excel 或其他运行库，无需配置环境、启动服务器或联网处理数据。程序和所需运行环境打包在同一个 .exe 中，支持 Windows 10 / 11 的 64 位电脑。

发布包只有程序和简短使用说明。结果默认保存在原文件旁，自动增加“_拆分填充”后缀，重名时增加序号，保留原表。

## 处理范围

- 支持 .xlsx、.xlsm，可多文件批量处理，默认包含全部工作表。
- 默认只拆纵向合并，保留横向表头；可勾选“同时拆开横向合并”。
- 例如 A2:A5 合并显示“华东仓”，处理后每一行都填入“华东仓”。跨行跨列区域默认逐行保留横向合并。
- 普通空白保持原样；保留零值、布尔值、日期和文本编号的类型。
- 处理过程完全在本机完成，Excel 文件不上传服务器。

合并区域含公式时，会提示先将该区域“粘贴为值”；被合并掩盖的独立内容会提示核对，避免覆盖。选中合并区域含单元格内图片等未支持的元数据时，会明确拒绝处理。旧版 .xls、密码加密及带文档数字签名的文件不在支持范围。详细规则见 [使用说明](使用说明.md)。
