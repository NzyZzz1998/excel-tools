# Excel 数据处理工具

**拆开合并单元格，让每一行都有完整数据。**

## 开始使用

1. 下载 `ExcelTools-Windows-x64.zip`，**完整解压**到可写目录。
2. 双击 `ExcelTools.exe`，无需安装 Python、Excel 或额外运行库。
3. 选择一份或多份 Excel 文件，点击 **开始处理**。
4. 完成后查看结果，点击 **打开结果目录**。

结果保存在原文件旁，例如 `日明细_拆分填充.xlsx`。原文件保留；同名结果已存在时自动加序号，便于复查和回退。

面向 Windows 10 / 11 的 64 位电脑；本机 Windows 11 已有验收记录，干净 Windows 10/11 与 WPS 仍有待补证项。升级时将新包解压到新目录，运行其中的 EXE 并核对窗口版本；下载 `Source code` 不会更新旧程序。

## 哪些合并会被拆开？

| 场景 | 默认处理 | 勾选“同时拆开横向合并” |
|---|---|---|
| 纵向合并 `A2:A5` | 拆开，每行填原值 | 相同 |
| 横向标题 `A1:D1` | 保留标题合并 | 拆开，每格填原值 |
| 矩形合并 `A2:B4` | 拆成三行，每行保留横向合并 | 全部拆开，每格填原值 |
| 普通空白 | 保持空白 | 保持空白 |

默认处理全部工作表，包括隐藏工作表。保留零值、布尔值、日期和文本编号的类型；没有符合规则的合并区域时，提示“无需处理”，不生成多余文件。

## 大文件，测到了什么规模？

以下是 **v1.1** 的本机实测：日明细测量源码引擎，月表测量已发布 EXE。耗时受文件结构、磁盘和电脑配置影响，不能据此保证任意更大的文件都能完成。

| 实际文件 | 主表规模 | 处理耗时 | 峰值工作集 |
|---|---:|---:|---:|
| 日明细，约 9.6MB | 190,566 行 ×14 列 | 约 63.5 秒 | 约 72MiB |
| 月度缺货表，约 104MB | 757,636 行 ×22 列 | 约 6分46秒 | 约 295MiB |

月表输出独立核对 **16,667,988 个实体单元格**，并通过本机 Excel 内容对照。测量口径、产物身份与未覆盖范围见 [日明细验收](docs/releases/v1.1/large-data-acceptance-2026-10-09/report.md) 和 [月表验收](docs/releases/v1.1/monthly-data-acceptance-2026-10-09/report.md)。不同运行的峰值统计口径以各报告为准。

**v1.1.1 复验**：同一 104MB 月表约 6 分 43 秒、峰值工作集约 296MiB，输出与上面的已核验结果逐字节一致。[本版验收记录](docs/releases/v1.1.1/acceptance/report.md)同时包含 115 项回归、9 项独立验收和异常保存测试；本版没有承诺速度提升。

大工作表逐行处理，中间结果暂存在磁盘；系统临时目录和结果目录都需要可用空间。行索引仍占内存，压缩后的文件大小也不等于处理时的资源需求。

## 批次处理与恢复

- **只重试失败文件**：修好文件或权限问题后重试，已经成功的文件不重复处理。
- **安全停止后续文件**：等待当前文件完成，再暂停余下文件；随后可继续处理。
- **保留本轮规则**：重试和继续沿用任务开始时的选项。重新“开始处理”才创建新任务。
- **按文件查看结果**：不同目录的输入分别在各自目录生成结果，主按钮打开最近一次成功的目录，其余路径见日志。

运行中关闭窗口也会请求安全停止。任务记录保存在当前窗口，退出后不会自动恢复；输出文件仍保留在磁盘。

## 支持边界

| 情况 | 如何处理 |
|---|---|
| 旧版 `.xls` | 先在 Excel 中另存为 `.xlsx` |
| 合并区域包含公式 | 在副本中复制并粘贴为值后再处理；工具不计算公式 |
| 合并区域隐藏独立内容、元数据或存在相交合并 | 明确报错，避免覆盖原内容；按提示核对区域 |
| 密码加密、文档数字签名 | 暂不支持 |
| 工作簿中的宏 | 未修改的包部件保留，程序不执行宏 |

新增单元格格式取自锚点，边框外观可能与原合并块不同。更详细的行为、错误指引和数据保留说明见 [使用说明](使用说明.md)。

## 开发与验证

运行时使用 Python 标准库和 Tk；`openpyxl` 仅用于测试，Windows 包使用 PyInstaller 构建。

```powershell
# 运行桌面界面
python excel_unmerge_gui.py

# 或从命令行处理文件
python excel_unmerge_fill.py "日明细.xlsx"

# 安装测试依赖并执行回归
python -m pip install openpyxl==3.1.5
python -m unittest discover -s tests -v
```

需要指定工作表、从源码打包或查看 CI，请看 [开发说明](docs/开发说明.md)。CI 包含源码测试及独立目录下的便携 EXE 自检；业务正确性另有合成边界测试、真实输入核对及 Excel 客户端验收。

反馈问题时请附上程序版本、处理规则、错误提示和可复现的合成示例。业务原件、生成结果和本地产物均不应提交到仓库。
